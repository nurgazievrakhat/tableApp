# Установка TableEasy на Windows

## 1. Скачать

Файл `TableEasy-0.1.0-setup.exe` лежит в архиве `TableEasy-setup.zip` внизу
страницы последней сборки:
<https://github.com/nurgazievrakhat/tableApp/actions>

Открыть верхнюю строку списка → внизу раздел **Artifacts** → `TableEasy-setup`.

Архив нужно **распаковать** — запускать `.exe` прямо из окна архива нельзя.

Браузер по дороге может сказать, что файл «может быть опасен». Это обычное
предупреждение про любой `.exe`: выбрать **Сохранить** / **Сохранить всё
равно**.

## 2. Обойти предупреждение Windows

Установщик не подписан сертификатом разработчика — сертификат платный и пока не
куплен. Поэтому при первом запуске Windows покажет синее окно:

> **Система Windows защитила ваш компьютер**
> Приложение Microsoft Defender SmartScreen предотвратило запуск неопознанного
> приложения.

Кнопки «Выполнить» в этом окне **нет** — её надо открыть:

1. Нажать неприметную ссылку **«Подробнее»** под текстом.
2. Появится строка «Издатель: Неизвестный издатель» и кнопка
   **«Выполнить в любом случае»** — нажать её.

Это единственный неочевидный шаг во всей установке. Предупреждение говорит
ровно одно: Microsoft не знает, кто выпустил программу. Оно исчезнет само,
когда будет куплен сертификат.

## 3. Установить

Дальше обычный мастер: **Далее** → при желании сменить папку → **Установить**.
Программа появится в меню «Пуск» под именем **TableEasy**.

## 4. После установки

Загрузить первый прайс: вкладка **Прайсы** → **Загрузить прайс** → выбрать
файл `.xlsx` или `.xls`. Приложение само разметит колонки и покажет, что попадёт
в базу, — останется проверить и нажать «Загрузить».

## Обновление

Скачать новый установщик и запустить поверх старого — данные и настройки
останутся на месте. Предупреждение SmartScreen появится снова: оно привязано к
файлу, а не к программе.

## Где лежат данные

`%APPDATA%\table-easy-app\` — база `data.db` и папка `backups` с резервными
копиями. Копия снимается сама при запуске: не чаще раза в сутки и обязательно
перед обновлением базы, хранятся последние семь.

Чтобы перенести всё на другой компьютер, достаточно скопировать `data.db`.
